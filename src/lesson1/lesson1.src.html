Python 是用文字寫的

你打一行指令，電腦就做一件事。寫 Python 的程式叫 Thonny，這個網頁內有一個一模一樣的 Thonny 讓你用。它分兩部分：

  • Shell（下面）：按綠色 ▶ 執行（或鍵盤 F5）後，結果在這裏出現。>>> %Run 那一行是 Thonny 說「我開始執行你的檔案了」。

出錯時 Shell 會出現紅字，下面黃色的 Assistant 會用中文解釋是甚麼問題。先看英文名稱（例如 NameError）和行號。

第 2 章

Python 很在意空格和大小寫

學完這章你會：
  • 知道行首的空格（縮排）是有意思的
  • 知道 print 和 Print 不一樣
學
兩條和其他語言不同的規矩

一、行首的空格是有意思的

Python 用縮排（行首的空格，通常 4 個）表示「這一行屬於上一行」。看這個例子（if 第 4 堂才學，先看縮排就夠）：

if 5 > 2:
    print("五大過二")   # 前面 4 個空格：屬於 if

相反，一行普通的 print 前面不可以有空格。Python 一看到不合規矩的縮排，整個程式都不會執行。

二、分大小寫

print 和 Print 是兩個不同的名字。Python 只認識小寫的 print，打了大寫會出 NameError。

出錯時先看紅字最後一行的英文名稱（例如 IndentationError、NameError）和它說的行號，再看 Assistant 的中文解釋。
小結　普通一行不可以有行首空格；指令要小寫。出錯時先看紅字的英文名稱和行號。
第 3 章

print 可以印文字，也可以印數字

學完這章你會：
  • 分辨 3 + 4 和 "3 + 4"
  • 用逗號一次印幾樣東西
學
引號決定是文字還是計算

印文字

文字放在引號裏，印出來時引號不會顯示。雙引號 " " 和單引號 ' ' 都可以，但要成對。

print("你好")
print('你好')

印數字

數字不用引號。沒有引號的 3 + 4 會先計算，印出 7；有引號的 "3 + 4" 是文字，照樣印 3 + 4。

print(3 + 4)      # 7
print("3 + 4")    # 3 + 4

一次印幾樣東西

用逗號分開，Python 會自動在中間加一個空格。每個 print 印完會自動換行；print() 括號留空就印一個空行。

print("分數：", 95)
print()
print("完")
小結　有引號照印，沒引號會計；逗號分隔會加空格；每個 print 一行。
第 4 章

註解：寫給人看，電腦會跳過

學完這章你會：
  • 用 # 寫註解
  • 用 # 暫時關掉一行程式
學
# 後面的全部不執行

註解（comment）由 # 開始，到該行結尾為止，Python 會完全忽略。註解是寫給自己和同學看的：這段程式做甚麼、為甚麼這樣寫。

# 這是註解，不會執行
print("你好")  # 註解也可以放在程式後面
# print("這一行不會執行")

第 3 行是常用技巧：暫時不想執行某一行，在前面加 # 把它「註解掉」；之後要用時刪去 # 就可以，不用重打。

好習慣：每個程式開頭寫一行註解，說明程式名稱和你的名字。
小結　# 到行尾都是註解；註解掉比刪去安全。
