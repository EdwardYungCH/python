開始：第一個 Python 程式

0 / 10 分

Python 是一種用文字寫的程式語言。你打一行指令，電腦就做一件事。我們用 Thonny 這個程式來寫和執行 Python。

在 Thonny 執行第一個程式

  1. 開啟 Thonny。上半部白色的大格是編輯器，用來打程式；下半部「Shell」是輸出，結果會在這裏出現。
  2. 在編輯器打：print("Hello, World!")
  3. 按綠色 ▶ 按鈕（或鍵盤 F5）。第一次會叫你儲存檔案，檔名用 L01_你的名字.py。
  4. 看 Shell：出現 Hello, World! 就成功了。
print() 的意思是「印出來」。括號裏面放你想印的東西，文字要用引號 " " 包住。

語法：Python 很在意空格和大小寫

0 / 10 分

每種語言都有文法，程式語言的文法叫語法（syntax）。Python 有兩條規矩和其他語言很不同：

一、行首的空格是有意思的

Python 用縮排（行首的空格，通常 4 個）表示「這一行屬於上一行」。看這個例子（if 第 4 堂才學，先看縮排就夠）：

if 5 > 2:
    print("五大過二")

第 2 行有 4 個空格，表示它是 if 底下的動作。如果你刪去這些空格，Python 會報錯。相反，一行普通的 print 前面不可以有空格。

二、分大小寫

print 和 Print 是兩個不同的名字。Python 只認識小寫的 print。

3

輸出：print 可以印文字，也可以印數字

0 / 10 分

印文字

文字放在引號裏。印出來時引號不會顯示。雙引號 " " 和單引號 ' ' 都可以，但要成對。

print("你好")
print('你好')

印數字

數字不用引號。沒有引號的 3 + 4 會先計算，印出 7；有引號的 "3 + 4" 是文字，照樣印 3 + 4。

print(3 + 4)
print("3 + 4")

一次印幾樣東西

用逗號分開，Python 會自動在中間加一個空格。每個 print 印完會自動換行；print() 括號留空就印一個空行。

print("分數：", 95)
print()
print("完")
4

註解：寫給人看，電腦會跳過

0 / 10 分

註解（comment）由 # 開始，到該行結尾為止。Python 執行時會完全忽略它。註解是寫給自己和同學看的：這段程式做甚麼、為甚麼這樣寫。

# 這是註解，不會執行
print("你好")  # 註解也可以放在程式後面
# print("這一行不會執行")

第 3 行是一個常用技巧：暫時不想執行某一行，在前面加 # 把它「註解掉」，之後要用時刪去 # 就可以。

好習慣：每個程式開頭寫一行註解，說明程式名稱和你的名字。
