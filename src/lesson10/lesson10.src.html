第 3 章

開一次真正的 Thonny

學完這章你會：
  • 在電腦室開啟真正的 Thonny，貼上你的程式執行
  • 知道真 Thonny 和網頁模擬器的分別
學
中四用的就是它
  1. 在電腦室的電腦開啟 Thonny（開始選單搜尋 Thonny）。
  2. 把你在這個網頁寫好的專題程式全選複製，貼到 Thonny 上面的編輯器。
  3. 按綠色 ▶（或 F5）。第一次會叫你儲存：檔名用 L10_你的名字.py，存到老師指定的資料夾。
  4. 在 Shell 輸入你的測試數據，看結果是否一樣。
  5. 試試 Thonny 的 View → Variables，和 Debug（蟲仔圖示）→ Step over，和這裏的逐步執行是同一件事。

真 Thonny 的分別：程式存成 .py 檔案在電腦裏；錯誤訊息是英文（沒有 Assistant 的中文）；可以安裝其他模組；沒有執行時間限制，無限迴圈要按紅色「停止」。
