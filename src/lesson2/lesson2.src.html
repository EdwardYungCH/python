第 1 章

變量：給資料一個名字

學完這章你會：
  • 用 = 把資料放進一個變量
  • 把變量印出來，也可以改它的值
學
變量（variable）是一個有名字的盒子

上一堂每次都把文字直接寫在 print 裏。如果同一樣東西要用很多次，先把它放進一個變量，之後叫名字就可以。

name = "陳大文"     # 把文字放進叫 name 的變量
print(name)         # 印出盒子裏的東西：陳大文
print("你好，", name)
name = "李小明"     # 盒子裏的東西可以換
print(name)         # 李小明

一個 = 的意思是「把右邊放進左邊」，不是數學的「等於」。

名字怎樣改

  • 用英文字母、數字和底線 _；不可以用空格，不可以由數字開頭。
  • 分大小寫：name 和 Name 是兩個盒子。
  • 名字要有意思：score 比 s 好，my_name 比 mn 好。

印變量

變量不加引號。加了引號就變成印那幾個字母。

cls = "3A"
print("我讀", cls, "班")     # 我讀 3A 班（逗號會加空格）
print("我讀" + cls + "班")   # 我讀3A班（+ 直接黐在一起）
print("我讀 cls 班")          # 我讀 cls 班（引號裏的 cls 只是文字）
執行後看右邊 Variables 視窗：每個變量和它現在的值都列出來。
小結　名字 = 值 放進盒子；印變量不加引號；逗號加空格，+ 直接相連。
第 2 章

數據類型：文字還是數字

學完這章你會：
  • 分辨 str、int、float、bool 四種類型
  • 用 type() 查一個值是甚麼類型
學
Python 會記住每個值是哪一種
類型英文例子怎樣認
字串（文字）str"你好"、"3A"、"15"有引號
整數int15、-3、2026沒有引號，沒有小數點
小數float1.65、49.5沒有引號，有小數點
布爾（真假）boolTrue、False只有這兩個，開頭大寫

最容易混淆的是 "15" 和 15：有引號的是文字 15，沒引號的是數字 15。文字只能「黐」，數字才能「計」。

print(15 + 1)       # 16（數字相加）
print("15" + "1")   # 151（文字相連）
print(type(15))     # <class 'int'>
print(type("15"))   # <class 'str'>
type(x) 會告訴你 x 是甚麼類型。不肯定時就用它查一查。
小結　有引號是 str；數字分 int（整數）和 float（小數）；True／False 是 bool。
第 3 章

輸入：問使用者一條問題

學完這章你會：
  • 用 input() 問問題，把答案放進變量
  • 知道 input() 給的永遠是文字
學
input() 會停下來等你打字
name = input("你叫甚麼名字？")   # 括號內是問題，會印出來
print("你好，" + name + "！")

執行時 Shell 會印出問題，然後停住等你打字。你按 Enter 之後，打的字就放進 name，程式才繼續。

  • 問題後面不會自動換行，你打的字會緊接在問題後面。
  • 問題文字最好以「？」或「：」結尾，再加一個空格，看起來才整齊。
  • 不論你打甚麼，input() 給的都是文字（str）。打 15，得到的是 "15"。
想自己試：在模擬器執行後，Shell 會出現一個黃色輸入格，打字後按 Enter。
小結　變量 = input("問題")；答案是文字；程式會等你按 Enter 才繼續。
第 4 章

類型轉換：把文字變成數字

學完這章你會：
  • 用 int()、float() 把輸入變成數字再計算
  • 用 str() 把數字變成文字再相連
學
input 給文字，計算要數字

上一章說過 input() 給的是文字。所以這樣寫會出錯：

age = input("你幾歲？")
print(age + 1)      # TypeError：文字不可以加數字

解決方法是先把文字轉換成數字：

age = int(input("你幾歲？"))   # int() 把 "15" 變成 15
print(age + 1)                  # 16
函數作用例子
int()變成整數int("15") → 15；int(3.9) → 3（直接去掉小數）
float()變成小數float("1.65") → 1.65；float(5) → 5.0
str()變成文字str(16) → "16"，之後可以用 + 和文字相連
 
age = 15
print("明年你 " + str(age + 1) + " 歲")   # 數字要先 str() 才可以用 + 相連
print("明年你", age + 1, "歲")            # 用逗號就不用轉換
int("abc") 會出錯（ValueError），因為 abc 不是數字。之後學了判斷才處理這情況。
小結　int(input(...)) 是最常用的寫法；數字要 str() 才可以用 + 黐文字，用逗號則不用。
