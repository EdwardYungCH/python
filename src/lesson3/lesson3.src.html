第 1 章

數字：整數和小數

學完這章你會：
  • 分辨 int 和 float，知道除法的答案一定是小數
  • 用 round() 四捨五入
學
兩種數字

上一堂學過：沒有小數點的是整數 int，有小數點的是小數 float。計算時要留意一條規矩：用 / 除，答案一定是小數，就算除得盡。

print(10 / 2)      # 5.0（不是 5）
print(7 / 2)       # 3.5
print(3 + 4.0)     # 7.0（有一個是小數，答案就是小數）

四捨五入

小數太長時用 round()：第二個數是保留幾個小數位，不寫就取整數。

print(round(3.14159, 2))   # 3.14
print(round(2.718))        # 3
print(round(49.95, 1))     # 50.0
之後計 BMI、平均分這類會有很多小數位的東西，記得 round()。
小結　/ 的答案永遠是 float；round(x, n) 保留 n 個小數位。
第 2 章

算術運算符：加減乘除之外

學完這章你會：
  • 用 // 取整除、% 取餘數、** 取次方
  • 知道先乘除後加減，括號最先
學
七個算術運算符
運算符意思例子答案
+加7 + 29
-減7 - 25
*乘7 * 214
/除7 / 23.5
//整除（只要商，不要餘數）7 // 23
%餘數7 % 21
**次方7 ** 249

// 和 % 是一對：17 粒糖每包 5 粒，17 // 5 是可以包 3 包，17 % 5 是剩 2 粒。

sweets = 17
print("可以包", sweets // 5, "包")    # 3
print("剩下", sweets % 5, "粒")      # 2

先後次序

和數學一樣：括號最先，然後 **，然後乘除（* / // %），最後加減。不肯定就加括號。

print(2 + 3 * 4)      # 14
print((2 + 3) * 4)    # 20
小結　// 商、% 餘數、** 次方；先乘除後加減，括號最先。
第 3 章

賦值運算符：把變量改一改

學完這章你會：
  • 看懂 x = x + 1 這種「用舊值計新值」的寫法
  • 用 +=、-=、*= 簡寫
學
x = x + 1 是甚麼意思

數學上 x = x + 1 不成立，但 Python 的 = 是「把右邊放進左邊」：先計右邊 x + 1，再放回 x。所以 x 會大一。

score = 10
score = score + 5     # 先計 10 + 5 = 15，放回 score
print(score)          # 15

這種寫法太常用，所以有簡寫：

簡寫等於
score += 5score = score + 5
score -= 5score = score - 5
score *= 2score = score * 2
score /= 2score = score / 2
之後學迴圈時，count += 1（計數器）和 total += x（累加器）會天天用。
小結　x += 1 即 x = x + 1：先用舊值計，再放回去。
第 4 章

比較運算符：答案是 True 或 False

學完這章你會：
  • 用 ==、!=、>、<、>=、<= 比較兩個值
  • 知道比較的結果是布爾值 True／False
學
問電腦一條是非題
運算符意思例子答案
==等於（兩個 =）5 == 5True
!=不等於5 != 5False
>大於5 > 3True
<小於5 < 3False
>=大於或等於5 >= 5True
<=小於或等於5 <= 3False

比較的答案只有兩個：True（真）或 False（假），這就是上一堂見過的布爾值 bool。

age = 15
print(age >= 18)      # False
print(age != 15)      # False
is_adult = age >= 18  # 比較的結果也可以放進變量
print(is_adult)       # False
最常見的錯：一個 = 是放進去，兩個 == 才是比較。age = 18 會把 age 改成 18；age == 18 才是問「age 是不是 18」。
小結　六個比較運算符，答案是 True／False；== 比較，= 賦值。下一堂用它們來做判斷。
