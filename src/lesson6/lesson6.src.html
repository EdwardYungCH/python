第 1 章

for：數住做幾次

學完這章你會：
  • 用 for i in range(n): 重複 n 次
  • 知道 i 每次會變：0、1、2 …
學
已經知道要做幾次，就用 for

上一堂的 while 要自己寫計數器、自己加 1。如果事先知道要重複幾次，for 會幫你數：

for i in range(5):     # i 依次是 0、1、2、3、4
    print(i)
print("完")            # 沒有縮排：迴圈完結後才執行

range(5) 產生 0 至 4 共 5 個數（由 0 開始，不包括 5）。每一圈 i 拿一個數，縮排的行執行一次。

# 同一件事，while 要三行，for 只要一行
n = 0                  # while 版
while n < 3:
    print("你好")
    n += 1

for i in range(3):     # for 版
    print("你好")
不用 i 的時候也要寫它；range(3) 就是「3 次」。
小結　for i in range(n): 重複 n 次，i 由 0 數到 n − 1。
第 2 章

range 的三種寫法

學完這章你會：
  • range(a, b) 由 a 數到 b − 1
  • range(a, b, step) 每次跳 step
學
起點、終點、步長
寫法產生的數說明
range(5)0 1 2 3 4由 0 開始，不包括 5
range(1, 6)1 2 3 4 5由 1 開始，不包括 6
range(2, 11, 2)2 4 6 8 10由 2 開始，每次加 2，不包括 11
range(10, 0, -1)10 9 … 1步長是負數就倒數
 
for i in range(1, 6):
    print(i)           # 1 2 3 4 5，每個一行

for i in range(10, 0, -2):
    print(i)           # 10 8 6 4 2
終點永遠不包括：要印到 5，就寫 range(1, 6)。
小結　range(起點, 終點, 步長)；終點不包括在內；步長可以是負數。
第 3 章

用 for 累加和累乘

學完這章你會：
  • 用 total += i 把 range 的數加起來
  • 用 p *= i 乘起來，和算年年加息
學
迴圈前設初值，迴圈裏加或乘，迴圈後印
# 1 + 2 + … + 10
total = 0
for i in range(1, 11):
    total += i
print(total)           # 55

# 1 × 2 × 3 × 4
p = 1                  # 乘法的初值是 1，不是 0
for i in range(1, 5):
    p *= i
print(p)               # 24

年年加息也是累乘：每年的錢是上一年乘 1.05（利率 5%）。

money = 1000
for year in range(1, 4):
    money *= 1.05
    print(year, "年後：", round(money, 2))
加法初值 0，乘法初值 1。round(x, 2) 保留兩位小數。
小結　累加 total += i（初值 0）；累乘 p *= i（初值 1）。
第 4 章

turtle：用迴圈畫圖

學完這章你會：
  • 用 turtle 模組叫海龜前進和轉彎
  • 用 for 重複「前進、轉彎」畫出多邊形
學
海龜走過的路就是線

turtle 是 Python 內置的畫圖模組。畫布中央有一隻小海龜，你叫它前進，它走過的地方就留下一條線。

import turtle
t = turtle.Turtle()    # 造一隻海龜，叫它 t
t.forward(100)         # 前進 100 步
t.left(90)             # 向左轉 90 度
t.forward(100)

畫正方形要「前進、左轉 90°」四次，正好用 for：

import turtle
t = turtle.Turtle()
for i in range(4):
    t.forward(80)
    t.left(90)
指令作用
t.forward(d)前進 d 步
t.backward(d)後退 d 步
t.left(a)／t.right(a)左轉／右轉 a 度
t.penup()／t.pendown()提筆（移動不畫線）／落筆
t.color("red")改線的顏色
多邊形的規律：有 n 條邊，每次轉 360 / n 度。正方形 4 邊轉 90°，三角形 3 邊轉 120°。
小結　import turtle、t = turtle.Turtle()；n 邊形：for i in range(n): 前進、轉 360 / n 度。
