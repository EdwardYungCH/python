第 1 章

字串是一串字符，每個都有編號

學完這章你會：
  • 用 len() 數字串有幾多個字符
  • 用 s[0]、s[-1] 取出某一個字符
學
由 0 開始數

字串（string）就是引號裏的文字。它由一個個字符組成，每個字符有一個編號叫索引，由 0 開始。

字符Python
索引012345
負索引-6-5-4-3-2-1
 
s = "Python"
print(len(s))        # 6：一共 6 個字符
print(s[0])          # P：第一個
print(s[5])          # n：最後一個（索引 = 長度 − 1）
print(s[-1])         # n：-1 也是最後一個，由後數起
print("th" in s)     # True：s 裏面有沒有 "th"
最後一個字符的索引是 len(s) - 1，不是 len(s)；s[6] 會出 IndexError。空格和標點都算一個字符。
小結　len(s) 長度；s[i] 第 i 個（由 0 起）；s[-1] 最後一個；x in s 有沒有。
第 2 章

切片：取一段出來

學完這章你會：
  • 用 s[a:b] 取索引 a 至 b − 1 的一段
  • 省略 a 或 b 的意思
學
和 range 一樣：終點不包括
s = "Hello, Kowloon"
print(s[0:5])        # Hello：索引 0 至 4
print(s[7:14])       # Kowloon
print(s[:5])         # Hello：省略起點 = 由 0 開始
print(s[7:])         # Kowloon：省略終點 = 直到結尾
print(s[-7:])        # Kowloon：最後 7 個

切片不會改變原本的字串，只是取一份出來。要記住：s[2:5] 取 3 個字符（5 − 2），不是 4 個。

電話號碼、身份證、日期都常常要切："2026-10-14"[0:4] 是年份 "2026"。
小結　s[a:b] 由 a 到 b − 1；s[:b] 開頭起；s[a:] 到結尾。
第 3 章

字串方法與 f-string

學完這章你會：
  • 用 upper()、lower()、strip()、replace()、count()
  • 用 f-string 把變量放進句子
學
方法：字串自帶的工具，用一點叫出來
s = "  Hello, Kowloon  "
print(s.upper())            # "  HELLO, KOWLOON  "：全部大寫
print(s.lower())            # 全部小寫
print(s.strip())            # "Hello, Kowloon"：刪去頭尾的空格
print(s.replace("l", "L"))  # 把所有 l 換成 L
print(s.count("l"))         # 3：l 出現了幾多次

方法不會改變原本的 s，它只是交回一個新字串。要保留結果，就賦值回去：s = s.strip()。

f-string：把變量放進句子最方便的寫法

name = "小明"
score = 95
print("你好，" + name + "，你有 " + str(score) + " 分")   # 用 + 要自己轉 str，很麻煩
print(f"你好，{name}，你有 {score} 分")                   # f-string：引號前加 f，變量放在 {}
print(f"下次目標 {score + 5} 分")                         # {} 裏可以計算
記住引號前的 f，沒有它 {name} 會照字印出來。
小結　s.upper() 等方法交回新字串；f"…{變量}…" 把變量放進句子。
第 4 章

用 for 逐個字符處理

學完這章你會：
  • 用 for ch in s: 逐個字符看
  • 用 isdigit()、isupper()、isalpha() 判斷字符種類
學
for 不只可以數數字，也可以逐個字符走
for ch in "abc":
    print(ch)            # a、b、c 各一行

配合計數器，就可以統計字串裏有幾多個某種字符：

pw = "ab12cd3"
digits = 0
for ch in pw:
    if ch.isdigit():     # 這個字符是不是數字？
        digits += 1
print("有", digits, "個數字")   # 3
方法True 的情況
ch.isdigit()是 0 至 9 的數字
ch.isalpha()是英文字母（或中文字）
ch.isupper()是大寫字母
ch.islower()是小寫字母
ch.isspace()是空格
這些方法用在單一字符或整個字串都可以："123".isdigit() 是 True，"12a".isdigit() 是 False。
小結　for ch in s: 逐個字符；ch.isdigit() 等判斷種類；配合計數器統計。
