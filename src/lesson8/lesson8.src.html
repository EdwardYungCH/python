第 1 章

列表：一個變量裝很多值

學完這章你會：
  • 用 [ ] 建立列表，用索引取出和修改其中一項
  • 用 len() 數有幾多項
學
五個分數，不用五個變量

要記住全班的分數，不可能寫 s1、s2、s3 … 一個個變量。列表（list）讓一個變量裝很多個值，用方括號和逗號寫：

scores = [80, 65, 92, 47, 73]
print(len(scores))     # 5：有 5 項
print(scores[0])       # 80：第一項，索引由 0 開始（和字串一樣）
print(scores[-1])      # 73：最後一項
scores[3] = 50         # 把第 4 項改成 50（字串不可以這樣改，列表可以）
print(scores)          # [80, 65, 92, 50, 73]

列表可以裝文字：names = ["Amy", "Ben", "Cat"]；也可以是空的：names = []，之後再加。

索引由 0 開始；scores[5] 不存在，會出 IndexError。印整個列表會連方括號一起印。
小結　x = [a, b, c]；x[i] 取或改第 i 項；len(x) 項數。
第 2 章

加項、刪項

學完這章你會：
  • 用 append() 在尾加一項，用迴圈逐個輸入
  • 用 remove()、pop() 刪項
學
列表會隨程式執行而變長變短
names = []                 # 空列表
names.append("Amy")        # 尾加一項 → ["Amy"]
names.append("Ben")        # → ["Amy", "Ben"]
names.insert(0, "Zoe")     # 在索引 0 插入 → ["Zoe", "Amy", "Ben"]
names.remove("Amy")        # 刪去值是 "Amy" 的那項 → ["Zoe", "Ben"]
last = names.pop()         # 刪去最後一項並交回它 → last = "Ben"
print(names)               # ["Zoe"]

最常用的組合：用迴圈重複 input 和 append，把使用者輸入的東西逐個收進列表：

scores = []
for i in range(3):
    s = int(input("分數："))
    scores.append(s)
print(scores)              # 例如 [80, 65, 92]
append 真的改變了列表，不用寫 names = names.append(...)（那樣會變成 None）。
小結　x.append(v) 尾加；x.insert(i, v) 插入；x.remove(v) 刪值；x.pop() 刪尾。
第 3 章

用迴圈逐項看：總和、平均、最大、最小

學完這章你會：
  • 用 for s in scores: 逐項處理
  • 自己寫「找最大值」：先假設第一項最大，逐項比較
學
先假設第一項是最大，見到更大就換
scores = [80, 65, 92, 47, 73]
total = 0
for s in scores:           # s 依次是 80、65、92、47、73
    total += s
print("總和", total)        # 357
print("平均", total / len(scores))   # 71.4
biggest = scores[0]        # 先假設第一項最大
for s in scores:
    if s > biggest:        # 見到更大的
        biggest = s        # 就換
print("最高", biggest)      # 92

找最小值只需把 > 改成 <。Python 其實有 max()、min()、sum()，但這一堂要自己寫，因為「逐項比較」這個方法以後很多題目都用得着，考試也會考你追蹤這種程式。

起始值要用 scores[0]，不要用 0：如果全部分數都是負數，用 0 會找錯。
小結　for s in x: 逐項；總和用累加；最大值：先設第一項，逐項比較，更大就換。
第 4 章

搜尋與計數

學完這章你會：
  • 數符合條件的項目有幾多個
  • 逐項搜尋某個值，找到就記下位置
學
計數器加條件；搜尋就是逐項對比
# 數有幾多個合格（50 分或以上）
scores = [80, 65, 92, 47, 73]
passed = 0
for s in scores:
    if s >= 50:
        passed += 1
print(passed, "人合格")     # 4 人合格
# 搜尋：Cat 的分數是幾多？
names = ["Amy", "Ben", "Cat", "Dan", "Eve"]
scores = [80, 65, 92, 47, 73]
target = "Cat"
found = -1                   # -1 代表未找到
for i in range(len(names)):  # i 是索引 0 至 4
    if names[i] == target:
        found = i            # 記下位置
if found == -1:
    print("找不到")
else:
    print(target, "的分數是", scores[found])   # 兩個列表用同一個索引對應
用 for i in range(len(x)) 而不是 for s in x，是因為要知道位置，才可以到另一個列表取對應的項。
小結　計數：條件成立才 += 1；搜尋：for i in range(len(x)) 逐項比對，找到記下 i。
