第 1 章

函數：把一段程式包起來，改個名，隨時叫

學完這章你會：
  • 用 def 定義函數，用名字呼叫它
  • 用參數把資料交給函數
學
定義一次，用很多次

你早已用過函數：print()、len()、input() 都是別人寫好的函數。現在自己寫一個。

def greet():            # def 定義函數，名字叫 greet，括號後要有冒號
    print("你好！")      # 縮排的行是函數的內容（這時不會執行）
    print("歡迎來到中三")

greet()                 # 呼叫：這時才執行裏面的兩行
greet()                 # 再呼叫一次，又印兩行

函數可以有參數：括號裏的變量，呼叫時把值交進去。

def greet(name):        # name 是參數
    print("你好，" + name + "！")

greet("小明")           # name 變成 "小明"
greet("小芳")           # name 變成 "小芳"
定義只是「教」電腦這個函數做甚麼，不會執行；要寫 greet() 呼叫才會執行。定義要放在呼叫之前。
小結　def 名字(參數): 定義；名字(值) 呼叫；參數在函數裏當變量用。
第 2 章

return：把結果交回來

學完這章你會：
  • 用 return 讓函數交回一個值
  • 分辨「印出來」和「交回來」
學
交回來的值可以存起來再用
def area(w, h):         # 兩個參數
    return w * h        # 計完交回結果，函數就結束

a = area(3, 4)          # a = 12：把交回的值存起來
print(a)
print(area(5, 2) + 1)   # 11：交回的值可以直接計算

只用 print 的函數，結果印在螢幕就沒有了；用 return 的函數，結果可以存入變量、再計算、再交給另一個函數。

def is_pass(score):     # 交回 True 或 False 的函數
    return score >= 50

if is_pass(63):
    print("合格")
return 一執行，函數立即結束，後面的行不會跑。沒有 return 的函數交回 None。
小結　return 值 交回結果並結束函數；x = f(…) 把結果存起來。
第 3 章

三類錯誤：語法、運行、邏輯

學完這章你會：
  • 分辨語法錯誤、運行錯誤、邏輯錯誤
  • 知道每一類怎樣找出來
學
最難找的是沒有紅字的那種
類別甚麼時候發現例子怎樣找
語法錯誤
SyntaxError、IndentationError		程式開始前，Python 讀不懂漏冒號、引號不成對、縮排錯看紅字的行號，檢查那一行的符號
運行錯誤
NameError、TypeError、ValueError、ZeroDivisionError、IndexError		程式執行到那一行時才出錯，之前的行已執行變量名打錯、int("abc")、除以 0、索引超出看 Traceback 最後一行的名稱和行號；用測試數據找出哪種輸入會出錯
邏輯錯誤
沒有紅字		程式跑完了，但答案不對> 寫成 >=、range 終點少 1、print 縮排錯放進迴圈用已知答案的測試數據對一對；用「逐步執行」看變量每一步的變化
 
# 這個程式想計 1 至 10 的總和，沒有紅字，但答案是 45：邏輯錯誤
total = 0
for i in range(1, 10):   # 終點應是 11
    total += i
print(total)
測試數據要有三種：正常（例如 60 分）、邊界（剛好 50 分、0 分、100 分）、錯誤（-5、abc）。邊界最容易暴露邏輯錯誤。
小結　語法錯誤：開始前；運行錯誤：執行到才出；邏輯錯誤：沒有紅字但答案錯，用測試數據和逐步執行找。
第 4 章

逐步執行：一行一行看變量怎樣變

學完這章你會：
  • 用 🐞 逐步執行，每按一下「下一步」執行一行
  • 看 Variables 視窗找出邏輯錯誤發生在哪一行
學
黃色是「準備執行」的那一行，右邊變量變了會標黃
  1. 按工具列的 🐞 逐步執行。第 1 行會變黃，表示「準備執行它」。
  2. 按 下一步 ▶：執行黃色那一行，黃色移到下一行，Variables 顯示新的值，變了的會標黃。
  3. 迴圈裏的行會重複變黃，每圈一次。input() 會在 Shell 等你輸入。
  4. 按 ■ 停止 可以隨時離開。

邏輯錯誤的找法：先在紙上寫下你預期每一步變量應是甚麼，再逐步執行對照；第一個不同的地方就是錯處。
小結　逐步執行＝一行一行看；預期值和實際值第一次不同的那行就是錯處。
